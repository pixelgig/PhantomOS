# Roadmap

This is a direction, not a guarantee of features or dates. Current hardware target is the ESP8266; no mandatory recurring charges.

| Milestone | Scope | Status |
| --- | --- | --- |
| 0.1 | Local AP, dashboard, Wi-Fi discovery | Source implemented |
| 0.2 | Filtering, telemetry, local snapshots and reports | Source implemented; validation pending |
| 0.3 | Owner-network DNS, gateway and connectivity diagnostics | Planned |
| 0.4 | Safe GPIO, UART, PWM and analog diagnostics | Planned |
| 0.5 | Android companion; phone-supported BLE/NFC inspection and serial | Planned |
| 0.6 | Configuration backup, update and migration tools | Planned |
| 0.7 | Local monitoring rules and alerts | Planned |
| 0.8 | Modular tool interfaces and capability checks | Planned |
| 0.9 | Browser installer for validated binaries | Planned |
| 1.0 | Verified stable release, public docs and removal of temporary AI files | Planned |
| 2.x | Optional ESP32-S3 and compatible peripherals | Exploratory |

New features should be useful, legal, maintainable and fit resource limits. Community ideas and patches are welcome through GitHub issues and pull requests.
