# Community code of conduct

We welcome contributors of all backgrounds and experience levels. Be respectful, constructive and patient. Review ideas and code on their merits. Do not harass, threaten, discriminate, publish another person's private information, or repeatedly derail discussions. Respect consent and boundaries when sharing diagnostic data.

Report community issues to the repository maintainer using a private channel when possible; use GitHub's reporting facilities for urgent abuse. Maintainers may remove harmful content, close disruptive threads or restrict participation. Security vulnerabilities should follow SECURITY.md rather than public discussion.
